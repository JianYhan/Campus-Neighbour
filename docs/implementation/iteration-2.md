## 桌面与移动端

采用同一应用的两套响应式布局，数据和业务规则共用，不维护两套重复业务代码。

- **桌面，大于720px：** 顶部导航、商品多列、详情与表单宽布局、聊天左侧会话列表加右侧内容。
- **手机，720px及以下：** 底部逛一逛／消息／发布／交易／我的，商品双列、详情与主要表单单列；会话列表和聊天内容分屏，聊天页有返回列表入口。按钮提供触屏空间，输入字体不小于16px，并保留底部安全区。
- 调整窗口尺寸仅改变布局，不卸载当前表单或聊天组件，未发送消息与未保存编辑保持不变。切换到另一会话或另一交易时则隔离草稿，防止错发。
- 初步验证宽度360、390、768、1440px；具体执行记录见下方。响应式模拟不等于已经在所有实体手机、输入法和浏览器上完成兼容性测试。

### 先失败后修复的代表场景

| 场景 | Red | Green |
| --- | --- | --- |
| 列表 | limit无效、前端无法读取下一页 | 游标分页和加载更多通过，失败保留已加载项 |
| 预约权限 | 卖家给受限买家预约仍返回201 | 返回ACCOUNT_RESTRICTED且不创建预约 |
| 管理配置 | 没有编辑入口；专区启停遗漏说明与条件 | 完整编辑和字段保留通过 |
| 字段错误 | fieldErrors为空、图片ID错误类型500 | 422及具体字段原因 |
| 聊天补取 | 超过100条新消息产生断档，切会话残留失败消息 | 按afterCursor跨页补取并隔离会话 |
| 背景刷新 | 资料后台刷新覆盖草稿；会话详情短暂失败卸载输入框 | 草稿保留，临时失败提示重试；访问撤销仍阻断 |
| 阅读回执 | 在旧消息后又有新消息，接口仍返回0 | 返回真实剩余未读数量 |

环境配置失败不计作TDD的有效Red。测试数量不等于完整需求验收通过。

## 仍需继续完善或决定

1. 密码找回、真实校园认证、注销与数据保留、换物单方确认后的人工争议处理仍属于待确认规则，本轮没有擅自引入外部身份或邮件服务。
2. OpenAPI已有真实43个路径，部分Map请求仍缺精确字段schema；后续可改为显式DTO。完整商品表单编辑与初稿部分更新设计的差异保留。
3. 多数界面文案仍经统一useWords提供，尚未全部提取为独立i18next资源文件。支付仅展示，无模型API。
4. 公共字典、有效专区是全量小列表；大量字典数据需另行评估。会话按更新时间排序，持续新消息会改变列表位置；前端去重并在刷新后重取已加载页。
5. 换物请求未自动变为INVALIDATED；接受时进行版本与可交易状态校验，不会错误占用商品。暂不提供没有实现的“已失效”筛选。
6. 性能、完整键盘／屏幕阅读器、实体移动设备、应用容器镜像构建、生产HTTPS、备份恢复演练、上传孤儿清理及outbox运维仍需继续。本轮不等于生产上线验收完成。
