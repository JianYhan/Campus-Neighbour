## 范围与实施选择

按项目发起人“直接按方案实现”的要求，将文档中的候选规则作为首版默认值：邮箱注册、卖家创建预约、交易完成后双方各评价一次、换物双方确认、快捷问题预填确认、自由消息20个字素簇。它们仍可经团队评审调整，不代表取得学校系统权限。

实现入口：`apps/web/src`为前端，`apps/api/src/main/java/campus/neighbour`为后端；数据库迁移为`apps/api/src/main/resources/db/migration/V1__campus.sql`。业务按Accounts、Catalog、Chat、Trading、Administration、Images等服务划分，当前为一个Java包内的模块化服务。

## 实际版本与环境

- Java目标21；本机验证使用Oracle JDK 21.0.12.1。Docker/CI配置使用Eclipse Temurin 21，尚不能把本机结果当作这些环境的验证结果。
- Spring Boot 4.1.1、MyBatis-Plus Boot 4 starter 3.5.17、springdoc 3.0.3；Flyway、Security、Session等跟随Boot依赖管理。
- PostgreSQL 18.3、Redis 8.6.1，通过Docker及Testcontainers实测。
- Vite 8.3.0、Tailwind 3.4.19、React 19系列；完整补丁版本以`pnpm-lock.yaml`为准，包管理器10.33.0。
- 项目目标Node24 LTS；本机实际构建使用Node25.8.1，CI配置Node24，远程结果待检查。
- Maven Wrapper 3.9.12。构建依赖一次下载中断后，经官方仓库重新下载并校验，打包成功。

选型依据：[Spring Boot系统要求](https://docs.spring.io/spring-boot/system-requirements.html)、[MyBatis-Plus Boot 4安装](https://baomidou.com/en/getting-started/install/)、[Vite文档](https://vite.dev/guide/)。兼容结论主要来自本次实际构建和集成测试，不能只依据版本名称。

## 与初稿的明确差异及下一轮工作

1. 个人简介及课程背景集中存入users.profile JSONB，校园字典统一一张表，未机械拆成初稿的每张表；正式结构以Flyway迁移为准。
2. 图片首版接受PNG/JPEG，尚无WebP解码支持；限制5MiB及2000万像素。图片通过接口校验可见性，不把持久化目录直接公开。
3. 商品编辑接口当前按完整表单提交（带expectedVersion）；不能把它当成任意字段均支持的部分更新。
4. 商品及聊天历史支持游标分页；其他个人列表／管理列表暂返回最近100条，筛选参数尚未全部实现。扩大演示数据量前应补齐这些列表的分页与筛选。
5. Swagger生成真实端点清单，但部分Map请求体的字段类型不够精细；业务字段约束仍以人工接口契约和实现为准，下一轮宜改为显式DTO并补齐OpenAPI schema。
6. 前端双语通过统一`useWords`与语言偏好实现，i18next已接入但多数业务文案尚未拆到独立资源文件；后续提取不会改变用户功能。
7. 账号找回、真实校园认证、注销／保留期限、换物争议的人工解除、上传孤儿文件定期清理尚未实施，原本相关决定也未定稿。outbox目前单实例批处理，推送可重试，无限积压的告警与保留策略还需补充。
8. 后续需继续完善端到端自动化、账号受限的所有收尾边界、上传恶意样本、性能、可访问性及备份恢复。没有宣称已达到生产上线条件。

初稿继续保留设计目标，以上差异优先反映当前实际状态。团队评审可决定补齐顺序；此次不接入真实支付、模型API、学校身份服务或公网部署。
